## GTO 依据与课程边界

成片采用 GTO Wizard [How to Solve Toy Games](https://blog.gtowizard.com/how-to-solve-toy-games/) 正文中的极化对抓诈唬模型：22233 牌面、AA/QQ 等权对 KK、底池与剩余筹码均为 10，仅允许相应过牌/全下动作，无抽水。解析均衡为 AA 全推、QQ 推一半、KK 面对下注跟一半。已独立用精确分数复核双方无差异条件。

这是模型范围内的 GTO 教学，不冒称完整现金桌范围或商业 solver 导出。视频先说明模型，再推导频率，执行一次跟注，最后揭示撞上 AA；单次输牌不被当成推翻策略的证据。独立复测另用底池 20 / 下注 10 的原创模型，说明新 skill 没有依赖某一固定算例。

## 已固化的通用修复

| 发现 | 修复位置 | 通用行为 |
| --- | --- | --- |
| 旧 skill 将 GTO 定量依据限定为外部 solver，且允许任务停在不符目标的内容 | poker-director skill 与策略依据参考 | 接受可核验的求解结果或解析推导，包括原创推导；在配音前匹配学习目标、模型和证据。场景、时长、叙事和主题保持自由 |
| 真实客户端被填入课程标签 | skill 创作步骤 | 客户端采用自然桌名/玩家名，课程标题放在旁白和导演标签中；保留用户明确指定的外观选择 |
| 新建项目缺少约定中的 evidence 目录，空资源导出目录也不完整 | src/project/store.mjs | 新建与导出均提供 assets/evidence；旧项目缺目录也能导出成完整目录，已有依据随项目保留 |
| 长短字幕页停留时间相同，硬切字符可能留下短碎片 | 共享客户端 renderer | 优先按句子/分句分页，超长内容继续按词/字符回退；按文字量分配时长，预览与成片共用。没有段落长度、句数或时长硬限制 |
| 将单帧未完句误判为字幕丢失 | skill 格式说明 | 检查完整分页时间轴与 SRT。首轮实际为完整 11 页，没有文本丢失；错误诊断已纠正 |

没有新增服务、数据库、编辑方法、内容白名单或另一套渲染逻辑。字幕计时仍是阅读量估算，不声称逐词语音对齐。
