# Strategy teaching and evidence

Choose a scene whose supported strategy answers the user's learning goal. GTO teaching demonstrates an equilibrium strategy and its incentives in a stated game. Exploit teaching explains an adjustment under stated opponent assumptions. Pot odds, a plausible action or a scripted win alone do not establish equilibrium play.

## Choose evidence before producing audio

Use either a reproducible solver result **or an analytic equilibrium with a checkable derivation**. Published primary-source solutions and original derivations are both valid when the stated game and equilibrium can be verified. Label original analysis as such. A commercial solver export is not required. Select whatever game, hand, route or teaching structure best serves the request.

For sourced claims, read the source body or actual solver output, not only a search excerpt. Match the claim to the relevant board, player ranges and weights, positions, pot/stacks, allowed actions/sizes, rake and objective. Record the source or derivation and applicable parameters with the project evidence. General theory can support a concept, but cannot certify an arbitrary hand's precise action or frequency.

For an analytic solution, independently check the payoffs and best-response/indifference reasoning. Label it as an analytic solution. For solver results, preserve the inputs, result and convergence information available. State material model limits before using the numbers; distinguish range-level frequencies from one scripted action. Narration must use only information available at that moment. A public range assumption is different from knowing the opponent's actual cards.

If the first idea lacks evidence, find suitable evidence or choose another supported scene within the requested topic. A GTO request remains a GTO request; an opponent-read lesson does not fulfill it merely by adding a disclaimer. If the requested scope truly cannot be supported, state that gap explicitly.

## Turn the strategy into a lesson

Give each passage a concrete question, decision, comparison or consequence. Let the reason for an action and the next unresolved question carry the story. Choose pauses, action-free explanations, alternative routes and reveals to suit the content; there is no fixed beat count, duration, hand or narrative template. State uncertainty where it matters without repeating the same disclaimer throughout the lesson.

Before delivery, compare the actual script/actions with the requested learning outcome and the evidence. Check that frequencies describe the right game, that the sampled action is consistent with the stated strategy, and that the ending teaches the strategy rather than treating one win/loss as proof. Audience retention is an editorial aim, not a measured result unless actually tested.
