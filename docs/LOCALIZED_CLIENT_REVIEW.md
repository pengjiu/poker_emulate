## 牌局来源与人数

原片的两人河牌场景由制作 Agent 选择，不是真实牌谱录像，也不是系统只支持单挑。平台支持 2–9 人和任一街起始状态。本轮保留同一模型，便于直接比较画面和讲解改进。

模型依据为 GTO Wizard 的 [How to Solve Toy Games](https://blog.gtowizard.com/how-to-solve-toy-games/)：22233 公牌；下注前底池 10、双方后手各 10；对手 AA/QQ 等权，我们固定 KK，双方知道范围；限定过牌/全下、无抽水。AA 全推、QQ 推一半、KK 面对下注跟一半，仅对该模型成立。项目 evidence/model.md 保存题设与独立收益复核。

skill 现在要求作者区分“自行设计的模型”“有来源的实战牌谱”“多人桌打到当前只剩两人”。不强制人数、选题或叙事模板，也不凭空补出不存在的前几街。

## 中文讲解与 skill 修复

新增 [内地德州口播参考](../.agents/skills/poker-director/references/zh-cn-narration.md)，主 skill 在中文配音前显式引导读取。它给出语境、反例和审阅问题，保留作者选择词汇、故事、节奏与论证方式的自由。

- 使用目标观众熟悉的牌面与动作表达，如“KK”“后手十个大盲”“满池全下”“抓诈唬”。数字说明对象、分母和收益起点，避免直译腔或术语堆砌。
- 从具体决策切入，用对手能否针对你来解释策略。记忆点来自真实的推理差异；本片突出“下注里诈唬占三分之一”与“KK 跟注一半”两个分母。
- 按完整意思与行动节点编排旁白，字幕由系统分页；不再为了每句话单独切音频。新版为 10 段完整口播，约 55 秒跟注、56 秒亮牌，再复盘范围。
- 来源与模型范围在理解所需处说清，工程验收留在证据材料；不虚构真实牌谱、随机抽样或职业经历。
- 配音前冷读，生成后检查牌面字母、金额、比例及连续呈现；区分文本审阅、自动音频验证和真实试听。

本次由主 Agent 重写并制作，不冒记为全新 Agent 独立完成第二次全流程。另一个无上下文 `gpt-6.1-sol / low` 只读公开 skill、讲稿和场景进行冷读，指出共同已知范围、QQ 过牌收益起点和胜率表述三处问题，均已修订后重新生成受影响音频。[冷读原文](../artifacts/localized-client-review-20261101/cold-review/report.md)保留。

语音通过外部 `edge-tts` 调用 `zh-CN-YunxiNeural`，平台仍只导入音频、测量时长和同步输出；没有加入语音生成依赖或固定提供商。

## 验收结果与范围

- **74 项自动测试通过，失败 0；302 项画面检查通过。** 覆盖规则、项目、并发/取消/恢复、媒体、客户端与真实导演台操作。原始失败日志保留，修复前确实复现计时/控件问题。
- 遍历新片全部 4,851 帧的画面标记，独立枚举 33 种不同画面，逐种从实际 MP4 解码，并另取结尾，共 34 个样本；最低 SSIM 0.991861，无字幕溢出。另直接查看实际开场、动作、亮牌和结尾画面。
- 10 段音频与编码后的 MP4 进行 PCM 首尾相关性比对，最低 0.99033，最大偏移 5.25 ms；完整解码与视频规格通过。无讲稿提示或语言提示的 ASR 检测为中文，关键牌面、金额和频率与稿件一致；原始同音字误识别保留。
- 正式视频本机导出耗时 23.815 秒，采样峰值 RSS 约 1.58 GB、临时文件约 26.14 MB。仅为这一课程的实测，没有将历史 60 秒性能基准冒记为重新运行，也不据此推导通用倍数提升。
- 可移植课程通过公开 CLI 导出与正式预检，清单及 10 个音频哈希一致，策略、讲稿和语音依据随项目携带。源码发行包另外进行干净安装、doctor、构建和示例预检。

v1.0.0 的完整 A01–A17 仍为历史基线；本轮是变更路径验收。没有真人试听或观众留存测量，不将文本冷读、ASR 和编码验证当作“真人专家认证”或完播率保证。旧视频与失败记录保持原样。
