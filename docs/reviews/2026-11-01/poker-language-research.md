# 目标语言中的真实讲牌用语研究

检索与正文核对：2026-11-02。范围：中文为重点，补充英文、日文；为 `poker-director` 和六人桌第一视角课程提供表达依据，不修改规则、skill 或实现。

## 结论

专业讲牌中会自然混用圈内术语，不能把“语言设为中文”理解成“所有词都翻成完整中文定义”。中文原创创作者实际使用 AA、QQ、ALL IN、CBet、坚果同花听牌；日文官方教学使用 3ベット、Cベット、ナッツ、チェックバック。这些词不应因为“避免黑话”被一概排除。应按观众水平决定是否在首次出现时顺带解释，随后用简短、一致的说法。[Travis 原创 CBet 视频](https://www.youtube.com/watch?v=4rmgL9M8Ayw)、[Travis 原创手牌解说](https://www.youtube.com/watch?v=q4aNeARVAT0)、[GTO Wizard Japan](https://japan.gtowizard.com/blog/c-betting-ip-in-3-bet-pots/)

“像老手”可以通过具体判断、对范围的理由和街际计划实现；不必堆行业词，也不必虚构职业经历。Jonathan Little 的本人复盘从自己的位置、手牌和筹码说起，再解释下注、对手回应和下一步；这里的第一视角比无关的宏大开场更适合本项目。[本人署名实战复盘](https://www.cardplayer.com/poker-news/1638947-poker-strategy-with-jonathan-little-making-sure-you-get-paid-with-the-nuts)

以下材料核对的是公开正文、原创视频标题/说明及实际选手访谈。**本轮没有完整试听这些视频，也没有取得所有视频的逐字字幕；不把标题中的用词冒记为已核对的口播发音、语气或地区使用频率。** 对中文材料不推断作者籍贯；简体页面也不等于内地口语认证。

## 12 类概念的表达选择

下表是基于这些材料整理的**候选用法和编辑建议**，不是词汇白名单，不是所有地区/级别的统计结论。中文为面向内地玩家的稿件选词；具体同桌称呼或用户偏好可优先。英文、日文直接按目标语言组织思路，避免逐句翻中文。

| 概念 | 中文候选说法 | 英文 | 日文 | 需要防止的误用 |
| --- | --- | --- | --- | --- |
| all-in | all-in、全下、推进去、直接推 | all-in、shove；jam 按语境 | オールイン | 是投入后手；已经全下的玩家不再作普通下注决定。中文原生使用证据见上述 Travis/Andy 视频；日文见 GTO Wizard |
| nuts | 坚果、坚果牌、nuts；坚果同花 | the nuts、nut flush | ナッツ、ナッツフラッシュ | “坚果同花”不一定是全牌型最大牌；更不能把坚果听牌当成已成坚果。中文视频和 [Andy 的 nuts 解释](https://www.andypoker.com/cn/nuts/) 可区分当前牌力与后续变化 |
| open / raise | 开池、open、开到/加到某个数 | open、raise to | オープン、レイズ | “加到 9”与“再加 9”含义不同；原生例子见 Poker Guild 的本人行动叙述 |
| 3bet | 3bet、三 bet、再加注 | three-bet、3-bet | 3ベット、スリーベット | 指下注层级，不是固定三倍金额，也不是含混的“第三次加注”。定义以 PokerStars 为准；字形/读法见 JCS 及访谈 |
| cbet | cbet、CBet、持续下注、延续下注 | c-bet、continuation bet | Cベット、コンティニュエーションベット | 指行动线，不能自动等同诈唬或有强牌。Travis 和 [Andy 的专页](https://www.andypoker.com/cn/continuation-bet/)均保留缩写 |
| check / check back | 过牌、check；后位也过牌 | check、check back | チェック、チェックバック | check back 适用于有位置一方在前面过牌后跟着过牌；不要把面对下注的弃牌说成过牌。用例见日文坚果分析 |
| check-raise | 过牌加注、check-raise | check-raise | チェックレイズ | 先过牌后面对下注加注；不能与直接领先下注混用。实战用例见 Little 的本人河牌复盘 |
| value / thin value | 价值下注、取价值；薄价值 | bet for value、thin value | バリュー、バリューベット | 说明目标是哪类较差牌会跟；不是只要自己牌强就叫价值下注。[PokerStars 价值下注课](https://www.pokerstars.com/poker/learn/lesson/value-betting/)明确以较差牌跟注为目的 |
| bluff / bluff-catch | 诈唬、bluff；抓诈唬、抓 bluff；“抓鸡”按受众 | bluff、bluff-catch | ブラフ、ブラフキャッチ | 不需要为了“更专业”把所有短称展开成定义；但不能把靠胜率跟听牌也说成纯抓诈唬。含义见 PokerStars/Andy，真实选手用法见 Poker Guild |
| draw / backdoor | 同花听牌、顺子听牌、后门；draw 按习惯 | flush draw、straight draw、backdoor | フラッシュドロー、ストレートドロー、バックドア | 听牌不等于已成牌；说清追的是哪一类牌。中文原生例子见 Travis 坚果听牌视频，日文见官方坚果分析 |
| barrel / sizing | 打一枪、二枪、三条街；半池、三分之一池、超池 | barrel、half-pot、one-third pot、overbet | バレル、ハーフポット、オーバーベット | 不是每注都叫 cbet；“满池”要以这次下注前的底池为准。英文/中文词义见 PokerStars 与 [Andy 术语表](https://www.andypoker.com/cn/poker-term-%E5%BE%B7%E5%B7%9E%E6%89%91%E5%85%8B%E6%9C%AF%E8%AF%AD/)，日文见两篇 GTO Wizard |
| hand / position / stack | AA、KK、AK同花/不同花；BTN/按钮位、BB/大盲位、后手/有效后手 | pocket aces、ace-king suited/offsuit；button、big blind、effective stack | AA/KK、スーテッド/オフスーツ；ボタン、BB、エフェクティブスタック | 不必逐张念花色，除非花色决定推理；显示符号与实际读音分别检查。牌面缩写见 Travis，英日展开见 PokerStars/JCS/GTO Wizard |

中国语料中“全下”“全押”、诈唬/偷鸡/抓鸡，以及位置译名存在版本差异。Andy 同一术语表就同时收录 All In 为全下、Shove 为全押；这足以说明不能以单个简体页面建立唯一口语规范。对本项目建议优先用户已经给出的 all-in、坚果，以及新课程所需的少量词；不要把港台用词批量转简后当作内地发音和搭配。[Andy 术语表](https://www.andypoker.com/cn/poker-term-%E5%BE%B7%E5%B7%9E%E6%89%91%E5%85%8B%E6%9C%AF%E8%AF%AD/)

## 对当前 skill 的独立审阅

当前 `zh-cn-narration.md` 已明确不是白名单，也强调按行动节点分段，这些应保留。问题主要在引导不够全面，而非存在某个显式“禁用 all-in”的规则。

1. 例子偏向全中文，缺少用户明确要求的 all-in、nuts/坚果、3bet、cbet。末尾的“不要网络黑话堆砌”容易被 Agent 扩大解释为避开标准圈内简称。建议改成区分“实际通行术语”和“为了显得像老手而堆的词”，允许必要的中英混用。
2. “避免 A对、K对”的绝对写法没有本轮真人口播语料支撑。应把问题改成牌面读法是否自然、稳定、能被目标观众理解；“AA”“一对 A”等都可以按选定声音核对。不要用文字外观推断 TTS 一定如何发音。
3. 缺少目标语言获取语料的工作步骤：遇到新语言、地区或不熟悉术语，先找目标语言原创教练/选手的具体复盘或解说；记少量有用的选词及来源，随后写稿。无需为每片重做完整词典，也不强制每一个常用动作词都搜索一次。
4. 需要区分字幕、旁白和发音控制。字幕可保留 3bet/AKs；语音可能需要自然展开或引擎的读音标记。音频必须仍表达同一手牌和动作；不要为了让模型读得顺，把术语语义或数字改掉。无法从本轮文本资料认证某一 TTS 的读音。
5. “像专家”应以行动理由和信息边界衡量。可以带犹豫、短停顿或亮牌后的反应；不应每段机械重复“现在分析范围、计算赔率、作出决策”，也不应每街复述完整模型免责声明。语气自然是编辑目标，需要实际连续试听，不由 ASR 全对自动证明。

## 对六人桌第一视角验收的建议

以下是从用户目标和现有 skill 的信息边界推导出的制作检查点，不是引用某篇文章的唯一流程。

- 翻前六名玩家应真实参与同一条行动线；四家弃牌之后，仍保留原桌座位与已弃牌状态。翻后两人对战不应变成重新生成一张两人桌，也不应改动 hero 的固定观察位置。
- 旁白跟随当前自己的选择：例如先说明“前面弃到我，在按钮位拿到这手牌”，再说开池理由。到翻牌后，再按已知动作推对手范围；不在行动前报出对手尚未亮出的底牌或未来转河牌。
- 每个关键决定突出最有用的一两个理由，留出动作与发牌的视觉空隙。逐步详解不等于逐次宣读所有按钮、每个弃牌或每条完整牌型定义。
- 坚果、阻挡牌、后门、薄价值等术语只在实际解释这个决定时出现；避免为了展示术语覆盖率，把一手牌塞成词汇考试。没有匹配求解证据时，不附会精确的 GTO 百分比。
- 语音验收区分正确性与听感：数字、牌面、动作、语音语言可自动核对；自然停顿、重音、情绪是否舒服仍需连续试听。不要将同一个情绪强度套给每段，也不要把每句话单独断开后假装是流畅讲解。

以上建议可以沉淀为短的条件式参考与验收问题，避免增加固定脚本、必用术语数、统一开场或所谓“专家人设”。
