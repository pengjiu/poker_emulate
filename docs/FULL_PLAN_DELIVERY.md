# 完整教学制作计划：实现与验收清单

本轮从 PR #1 的 `df5d23d`（本地等价树 `ac54a82`）继续。用户明确要求完成前述完整计划，仅允许配音生成延期。本清单补充历史 P0 计划，不改写历史验收结果，也不再把缺少的功能列为本轮范围外。

## 统一设计

继续使用 v2 可选字段、唯一扑克规则、单一 Compiler / RenderPlan、预览与导出共用 renderer、六方法原子编辑。教学资料引用规则状态，表现只读这些资料。高级编辑在同一检查器展开，不建立另一套可变牌局。新增功能按职责置于分析、表现、课程/实战和媒体模块。

## 验收与发布

每项需要具体输入、实际输出与结果。运行数据写入新的 `artifacts/full-plan-*`，保留原有制作工程和历史报告。最终将实现、skill、样例、测试与本记录更新到同一 PR；不合并 PR，不恢复 GitHub Actions。真实学习效果以可作答练习与试学记录支持，不把自动测试或模拟评审写成真实观众的学习增益实验。

当前验收明细见 [完整教学制作能力验收](FULL_PLAN_ACCEPTANCE.md)。源码和功能已完成，最终媒体矩阵仍在本轮制作队列中；这不是将功能移到后续计划。
