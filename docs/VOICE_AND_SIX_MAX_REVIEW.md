## 讲牌表达与场景

术语不再按“所有英文都换成完整中文定义”处理。skill 引导作者参考目标语言的原创教学、本人复盘和解说语境，允许 all-in、nuts/坚果、3bet、cbet 等自然混用；需要时才顺带解释。3bet 是行动层级，坚果听牌不是已成坚果，牌力和阻断也不能混为一谈。[一手语料研究](reviews/2026-11-01/poker-language-research.md)记录正文、原创视频标题/说明与证据边界，不把标题词语冒记为已试听的发音。

新课从六人桌翻前开始，英雄始终在大盲拿 K♠9♥。前三位弃牌、按钮开到 2.5、小盲弃牌、大盲跟注，随后两人打完 J♠5♥2♠ K♦8♠。四位弃牌玩家留在原座位，桌面、英雄、筹码和历史持续，不切成新建的两人桌。旁白在每个决策解释“我为什么继续、接下来要看什么”，不提前知道对手底牌。

课堂采用 GTO Wizard [组合与阻断的公开解例](https://blog.gtowizard.com/a-beginners-guide-to-poker-combinatorics/)行动线，并由制作方补充一次 A♠Q♥ 亮牌结果；不是原始实战录像或新求解的完整 GTO 认证。桌面没有自动抽水，不照搬源文的舍入阈值或频率。当前筹码下的跟注门槛独立计算为 27/85.9≈31.43%。[课程依据](../artifacts/six-max-index-tts-20261102/project/evidence/strategy.md)保存参数、来源、补充内容与筹码复核。

## 本地声音与界面

默认调用官方 [IndexTTS2.5](https://github.com/index-tts/index-tts/blob/main/docs/README_zh.md)，固定源码提交和模型 revision。安装器按网络探测选择 Hugging Face/ModelScope，逐文件核对固定内容哈希，约 7.1GB 必要权重；不下载无须使用的 Qwen 情绪文本模型、训练优化器或另一份语义编码器。`.river/` 和 Python 环境均留在本机。

导演台提供生成本段、补全本路线、取消、试听、更换参考音色，以及折叠的声音设置。语速、八维情绪和强度可自由配置；“仅本段”允许计算、推理、结尾等段落分别控制。字幕保留作者写法，发音提示单独影响语音。本片将价格、阻断与结尾三段单独调整，不改变其他段落的默认设置。

同一批次只构造一次官方模型，生成后进程退出。工作发生在项目编辑锁外；音频全部生成、探测成功且修订仍匹配后才原子提交。参考音色和音频进入内容寻址资产，随课程导出。手动导入外部音频继续可用，默认模型不可用时不会暗中换成其他 TTS。

真实 IndexTTS 在本机 Apple M4 Pro 的 MPS 上完成中文主课以及英文、日文短片。安装文件存在只代表环境齐备；这里另保留了真实生成证据。[引擎研究](reviews/2026-11-01/indextts-research.md)区分官方代码可选设备与本机实际通过的范围。

## 独立 review 与通用修复

Standards 与 Spec 两轴以只读 v1.0.2 源码包为基线，分别审阅；[Standards 原报告](../artifacts/six-max-index-tts-20261102/review-standards.md)和[Spec 原报告](../artifacts/six-max-index-tts-20261102/review-spec.md)保留最初发现、修复复核和证据范围。

| Standards 发现 | 修复 |
| --- | --- |
| 最后一次音频导入期间接受取消，仍可能提交 | 在清单原子替换前统一检查取消；进入短暂 committing 阶段后，取消明确返回 false，避免承诺撤销已提交结果 |
| 新增声音配置未进入项目内容指纹 | 内容哈希纳入声音配置，段级配置本身属于场景；预览、生成失效判断共用有效配置 |
| 新任务阻挡旧成功请求的精确回放 | ProjectStore 统一回执读取；活动任务期间也可返回旧回执，不改动当前任务 |
| 异内容修复后留下无引用坏资产，导致课程导出失败 | 项目保存只清理明确缺失/损坏且在所有场景、分支、音色中均无引用的索引；有效素材库和引用中的草稿保留 |
| 清理把 EACCES 等读取失败误当损坏 | 只认明确内容不符或 ENOENT/ENOTDIR；无法判断的索引保留，导出仍准确报告访问错误 |

| Spec 发现 | 修复 |
| --- | --- |
| 同一 NDJSON session 的取消被生成任务挡住 | 语音 status/cancel 可穿过长任务；其余编辑/导出请求维持顺序，预备阶段也接受取消 |
| 磁盘音频缺失/损坏仍被判为齐全 | 补全先验证实际文件；新音频暂存、探测后原子发布，可恢复正确的内容寻址资产 |
| 先改语速再勾选“仅本段”会丢失输入 | 切入局部范围保留表单草稿；恢复继承时才载入默认值，旁白与配置一起保存 |

实际成片检查另暴露两项工具/布局问题，也已泛化修复：右侧庄家标记改为朝牌桌内侧摆放，2–9 人桌所有 88 种人数/位置/画幅组合检查边界；大量抽帧改为分批构造 FFmpeg 选择表达式，130 个非连续帧的真实回归不再触发解析上限。未限制课程长度、场景种类或作者用词。

语音仍只是第六个 Director 方法，没有新增服务、数据库、队列或规则实现。持久化与回执仍由 ProjectStore 负责，Python 只调用官方模型；预览和视频继续共享 renderer。

## 冷启动与验收证据

另一个全新无上下文 `gpt-6.1-sol / low` 仅用公开 skill/README，完成六人翻前到两人翻后的小场景、真实英文/日文 IndexTTS 语音、正式 MP4 和可移植项目。无源码阅读、无测试替身、无命令错误。首轮自主记录了日语标签仍为英文；一次验收反馈后已修正，skill 也补充检查作者填写的标题/标签是否真正本地化。[首次报告](../artifacts/six-max-index-tts-20261102/cold-skill-trial/report.md)和[修订报告](../artifacts/six-max-index-tts-20261102/cold-skill-trial/report-after-localization.md)分别保留，不冒记为零反馈全通过。

**90 项自动测试、302 项画面检查通过。** 横版抽取176个、竖版197个实际编码帧样本，共373个；完整字幕与12段音频均已比对，最大音频偏移5.25ms。

最终 qualification 分开记录自动测试、画面矩阵、实际 MP4、语音模型、冷启动与干净安装。主课核对固定英雄、六个座位、翻后两个参与者、亮牌前信息、最终筹码和完整字幕；横竖版逐种解码不同画面，并与预览及源音频比对。实际 MP4 的无讲稿提示 ASR 另核对中、英、日语言与内容，原始同音字误识别保留。

历史七片矩阵、旧 60 秒性能基准和其他操作系统没有冒记为本轮重新验收。文本审阅、波形比对和 ASR 不等同真人主观试听、专业教练背书或观众完播率测试。模型声线与自然度可在导演台试听、换参考音色并按段调整。
