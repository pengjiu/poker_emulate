## 范围与方法

在 PR #1 原已发布树 `ac54a82` 上继续完成全部计划，仅延后新配音生成。独立 Standards 与 Spec 两条审查以 `8c032b3…bde5a91` 为固定范围，分别核对 `AGENTS.md` / `CONTRIBUTING.md` / 项目 skill 与 `docs/FULL_PLAN_DELIVERY.md` F01–F19、原执行计划。没有把工程回归、作品审查和真实观众学习效果混为一项。

本记录保留首轮发现与根因修复；最终全量回归和编码交付数据在新的完整验收报告中汇总。原教学和发布报告继续作为历史证据，不改写成新版本的通过记录。

## 其他实际发现与修复

- 冷启动创作发现 session 导出混用了内部百分单位和作者单位；统一转换并新增大盲 2、BBA 2 的公开导出回归。
- 九个物理槽位中，新玩家替换前大盲的空位后，旧玩家 ID 不能再定位座位；改为按原物理位置推进盲注。
- 手填状态省略单位但大盲不为 1 时，默认显示 `chips`，保持旧单位盲注工程的行为。
- 条件对照曾漏掉“组合数与总权重均相同、具体权重改变”的情况；现在返回范围变更、受影响组合/手牌和数值类型，观众看到的是玩家昵称与本地化字段。
- 范围、公式和指标同时出现时，竖版画布拥挤；按整段揭示预留稳定位置，压缩重复上下文并让短标记避开牌张及正文。
- 变式重建时删除旧 review 会把“原资料失效”退化成“从未审核”；保留原指纹，让 `ANALYSIS_STALE` 保持可追溯。
- 全量首轮 206 项回归中，1 项浏览器测试先删除目录、后关闭服务，触发运行锁异常；调整为先关闭浏览器与服务，再删除临时目录。保留首轮失败日志，后续全量结果另记。
- 随后 214 项回归命中真实导演台竞态：用户在 `seek` 未完成时展开高级工具，异步刷新重建检查器并把工具折叠。网络闸门回归在修复前 684 ms 内稳定复现；本地视图状态现在保留明确的展开或关闭，定向 3 项浏览器检查通过。没有增加超时、强制点击或重试。
- 冷启动导出练习至已有文件时，底层 `EEXIST` 曾被报告为不明确的内部错误；现在返回 `DESTINATION_EXISTS`，保留原文件，并在公开导出回归中验证。
- 最终依赖核对发现子章节缓存仍缺捕获实现身份：最终媒体失效后可能继续复制旧章节。新增 `visualImplementationHash`，包含捕获/编码文件与章节编排文件，进入章节键、子回执和最终回执；纯混音实现仍只影响最终媒体。完整字节但身份错误的章节被真实渲染回归拒绝，12 项相关检查通过，独立 reviewer 确认闭环。
