关键原因链（5 Why）：

1. **“文件生成”为什么不等于“讲解完整”？** 模型可能省略或含混读出一段 → 哈希绑定的是输入文字 → 编码器忠实保留的也可能是有缺陷的源音轨 → 头尾波形仅验证传输 → 因此源口播语义审阅和完整成片波形验收必须分别承担责任。系统不伪造自动自然度认证，skill 要求基于实际音轨复核关键事实，受影响段落重配后重新验收。
2. **为什么合法场景仍会讲错？** 动作顺序合法 → 旁白可以引用尚未出现的牌 → 以章节标题代替当时公开状态 → 生成脚本没有通过完整决策片段复审 → 因此预审和成片复审必须读取同一 Compiler 的当前状态与真实音轨时序，不能只读计划标题或首尾关键帧。
3. **为什么有计算和练习仍可能没有教学迁移？** 数学算式局部正确 → 两边假设可能同时变化 → 短片可能缺少前提 → 题目可能已在旁白给过答案 → 因此 skill 明确共同假设、独立短课前提和新条件练习，源码样例与对应回归落实这些要求；不增加限制 Agent 题材和叙事自由的固定模板。
