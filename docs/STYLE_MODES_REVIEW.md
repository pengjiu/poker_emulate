# 讲解模式与连续制作验收（1.2）

本轮把风格做成可执行的创作约定，把牌局、桌型、语言与风格分开选择。导演台和 Agent 读取同一个模式目录；规则、编译、语音、预览和视频继续使用原来的单一路径，不增加服务、队列或第二套牌局引擎。

## 调研与分类

[中文研究](reviews/2026-11-02/style-research-zh.md)覆盖 5 位创作者、10 个具体作品，另有官方课程结构；[国际与日语研究](reviews/2026-11-02/style-research-global.md)覆盖 9 个作者/官方栏目群、16 个样本。正文、课程介绍、元数据与访问受限的索引证据分级记录。没有完整核听全部视频，没有后台留存或完播数据；公开传播量不能证明某个机制最受欢迎。下面是研究与产品需要共同导出的分类，不是网红排名或声线复刻。

| 模式 ID | 主机制 | 常用场景（可自由变更） |
| --- | --- | --- |
| think-aloud | 当前信息→顾虑→备选→选择→下一街更新 | 六人/九人翻前、翻后单挑或多人，固定自己席位 |
| hand-story | 真实难题→逐街升级→揭晓→回到判断质量 | 单手复盘、一次比赛中的关键手 |
| decision-quiz | 完整条件→提问→真实留白→答案与边界 | 单点判断、反常识练习、新手测验 |
| fundamentals | 具体问题→必要概念→示范→小变体再判断 | 位置、尺寸、下注目的、基础赔率 |
| range-lab | 假设→匹配模型/证据→检验→修正→适用边界 | 范围、组合、阻断、单挑/多人条件对照 |
| exploit-clinic | 基线→观察/假设→有条件调整→失效时退回 | 现金局对手倾向、已知人群漏洞 |
| table-commentary | 连续行动→抓关键节点补因果 | 多人底池、单挑决战、主边池、赛事片段 |
| dialogue | 稳定的提问/组织角色与分析角色 | 新手追问、专家讨论、双人赛事解说 |
| line-comparison | 同决策起点→实际线/备选线→权衡 | 逐街纠错、尺寸对照、反事实演示 |
| theme-series | 一个贯穿问题→标准例→变化例→反例 | 多手主题课、session 关键手、系列章节 |

短视频主要改变篇幅、节奏与取舍；锦标赛、六人桌、多人池等是牌局条件。两者都不必复制成新的人设。10 个预设是起点：可改任意文字约定、结构、信息视角、声音建议，允许主模式组合其他机制，并允许完整自定义。

## 权威与流程

- `src/direction/patterns.json` 是目录唯一来源。`export kind:patterns` 先返回短索引，指定 patternId 取完整资料；导演台使用同一接口数据。
- `direction.set` 保存完整快照和来源版本/哈希；项目默认，场景可覆盖，删除覆盖则恢复继承。旧课程不会随目录更新而改变。约定本身不自动生成台词，不改变合法行动，也不声称认证文案效果。
- 模式的声音参数是建议，通过现有 voice.set 明确应用；既有音色可保留。仅改创作约定不会使音频无端过期。
- `beat.timing` 是相对段落起点的动作和旁白时刻。编译器统一量化为帧，生成唯一语音时钟；预览、混音、字幕和 SRT 共享它。动画另锚定实际动作时刻，切分解释不重启动画。
- 配音后的 `timing.set` 按语言确认动作时序并绑定音频，支持不同语言用不同时间；换旁白后 `TIMING_STALE` 阻止静默沿用旧时间。仍由同一编译器执行。编辑时序的弹窗捕获打开时修订，后台改动后不会用旧值确认新音频。
- `captions.set` 可把精确字幕绑定当前音频，保持文字完整和揭晓时点；换音频后须重新核对绑定，改稿保留待修的精确字幕状态。子帧而完全不可见的字幕、超长/重叠或旧音频时序不会静默放行。普通段落保留自动分页。
- 预览在旁白加载/播放期间使用音频主时钟，正常缓冲期间画面随之等待；真实播放错误停止并提示。跨章同步刷新编辑上下文，开始编辑即暂停，避免把旧稿保存到新章。
- `output.sequence` 按项选择场景/分支，可重复。每项由规则引擎从该场景起点运行，精确 frameId 加 entry 前缀，重复 beatId 必须指定 entryId 或 frameId。跨手筹码/位置连续性由作者明确编排，不自动猜测。
- `beat.speaker` 标明角色；局部 voice.set 导入其独立参考，批次冻结全部参考后只启动一个模型 worker。轮次依次播放，重叠对白可外部预混导入。
- 真实客户端不显示模式、教程、Hero 等导演元数据。章节切换、反事实、知识范围由作品旁白明确；风格研究来源与策略证据分别保留。

## 可执行验收合同

| ID | 要求 | 方法与通过标准 |
| --- | --- | --- |
| P01 | 目录/自定义/本地化 | 10 预设 ×3语言完整；新模式和组合可保存，无封闭角色/桌型白名单 |
| P02 | 快照/治理 | 重开、精确重试、导出保留约定；项目与场景继承清晰；无额外服务或重复规则权威 |
| P03 | 连续旁白 | 同一真实音频跨至少3个动作，预览只创建一次音源，编码混音只放一次，字幕不回到开头 |
| P04 | 多手与分支 | 至少3播放项，重复场景/分支可定位，状态按项重置，选单场景退出序列，比例/语言切换保留序列 |
| P05 | 双说话者 | 两个不同参考的实际合成；每段记录真实参考哈希；不拿情绪变化冒充不同角色 |
| P06 | 信息与复杂牌局 | 首视角不偷看底牌/未来；竞猜有真静音；多人/边池由原规则计算；重启解释不重启视觉动作 |
| P07 | 模式一致性 | 独立无上下文 Agent 用同模式处理两个不同决策，再做互动题；保留实际讲稿、问题和修订，不以渲染成功代替内容审查 |
| P08 | 导演台操作 | 模式选择、场景覆盖、顺序、时序、局部声源经过真实浏览器操作；中英日标签完整；清洁客户端无导演控件 |
| P09 | 实际媒体 | 不同风格真实语音与横/竖输出；检查实际编码帧和完整音轨位置，对源图 SSIM≥0.97、音轨相关性>0.95、偏移≤1帧 |
| P10 | 发布与回归 | 原有测试及新增契约/界面/媒体测试通过；干净源码包安装、doctor、build、验证通过；保留旧版本与用户工程 |

## 结果与边界

本轮运行证据保存在 [固定验收目录](../artifacts/style-patterns-20261102/qualification-1.2.0.json)。104 项 Node 测试、302 项画面检查通过。四片共 7,512 帧，逐一枚举 701 个不同画面，再连同结尾解码核对 705 帧；最低 SSIM 0.989059。24 个音频播放实例的源波形相关性最低 0.9751，偏移最多 5.25ms。完整字幕均可显示，实际音轨中的竞猜留白持续5秒，RMS约1.33×10⁻⁸。

冷启动作者使用 `gpt-6.1-sol / low`，无上下文，通过公开skill/API制作。初稿不能按“已渲染”直接验收：昵称/语句、整片泄题、具体理由不足、跨beat时态及改配音后旧动作时间等问题依次被实际审稿或ASR/帧核对发现。原始影片、报告和失败保留，最终revision11经[独立编辑复核](reviews/2026-11-02/style-cold-editorial.md)可用。相关流程修复进入通用skill：先整片脚本/状态审稿再全批配音，完整决策思考结束再提交动作，生成后核对全部行动事实，按语言确认时序与精确字幕。

工程验收、文本/抽帧编辑验收已通过。四片实际MP4的独立ASR均识别为中文，ASR包含同音字与字母识别错误，保留原结果，未用它证明发音逐字无误。没有真人连续听评或受众留存实验；不将这轮结果称为复刻某名人的声音、证明风格更受欢迎或认证GTO最优。新模式已做目录/契约检查，本轮真实成片覆盖跟打、竞猜、现场解说、双声和对照机制；未声称十种模式全部做过受众效果比较。

### Standards

[独立工程审查](reviews/2026-11-02/style-standards-review.md)发现5项：预检与编译选路不同、显式主线回退错支线、跨章旧稿写入新章、子帧字幕静默丢失、播放后发错误冻结。均已关闭；追加语言时序、精确重试和已刷新/未刷新修订竞态验证通过。最严重的P1预检问题已关闭，未决0；没有要求另建运行时或为重构而重构的异味建议。

### Spec

[独立需求审查](reviews/2026-11-02/style-spec-review.md)发现4项：选路预检、显式主线、不可见字幕，以及仅保存字幕时被默认时间表误切为并行播放。均已关闭，时序弹窗保留未配置的null，显式启用才产生草案。最严重的P1选路问题已关闭，未决0。两个轴分别保留发现，不把重复发现算作额外功能或合并评分。

“适配任意风格”的可执行含义是开放创作约定，底层支持逐街、停顿、跨动作解说、多手、反事实与多声源，Agent 可以组合；不表示内置了任意形式的视频编辑器、ICM/自动抽水求解器或同时对白混音器。范围图等额外分析素材可在旁白中解释，当前清洁客户端不内置任意图层编辑。策略主张仍按原证据规范验收。
