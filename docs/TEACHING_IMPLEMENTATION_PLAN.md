# 决策教学改造：评审、边界与验收

基线为 `8c032b3`（River Studio 1.2.0）。沿用 v2 项目、六方法、唯一规则引擎、Compiler、共用客户端和本地验证；不新增 GitHub Actions。

## 评审结论

第三方方案的收敛方向成立：先建设可复用的分析资料与表现编排，再由真实作品决定下一轮投入。研究画布、前提与反例、实际口播排演应保留。需要进一步落实的内容是节点语义、可见信息边界、变更后阻止旧结论进入成片，以及真实声音验收与自动媒体检查的区别。

这次改造不引入另一份牌局状态。分析引用某个 beat 或其某个动作完成后的状态；分析画布只读该状态。画面以牌桌和分析画布两种表面组合，聚焦、范围、公式、提问与逐步揭示复用同一数据。每一帧都包含完整的表现快照，随机跳转与顺序播放一致。

## 对第三方方案的具体取舍

| 建议 | 本次决定 | 工程理由与观众收益 |
| --- | --- | --- |
| 稳定研究画布与逐步揭示 | P0 实现 | 上下文、范围与计算保留位置，讲到哪一步再显示哪一步，减少观众重新寻找信息的负担。 |
| 记录判断方法及适用条件 | P0 实现 | 资料引用决定，保存假设、条件、目标与结论；牌张和金额仍从规则引擎读取。 |
| 第一轮就使用真实口播 | P0 制作门槛 | 先测真实声音，再决定提示点和片段长度；测试信号与真实配音分别记录。 |
| 任意跳帧、分析后返回 | P0 实现 | 编译出完整表现状态；返回只换视图，行动由原有规则轨迹执行一次。 |
| 安全变式与失效处理 | P0 实现 | 指定动作替换后重放；公开历史、决定及分析资料参与审查，机械重算和内容复核分开。 |
| 可核查策略依据 | P0 加强 | 本地依据文件绑定实际内容哈希；替换文件后旧确认与旧渲染缓存不能掩盖变化。确认表示作者审查，不表示系统证明所有策略主张。 |
| 一套新格式、四个工作面、三类新接口 | 暂不建设 | v2 可选字段、现有检查器和六方法足够承载本轮作品；减少迁移、交叉状态与维护入口。 |
| 教学单元成为所有作品的必填结构 | 改为可选课程资料 | 系统支持自由讲稿和短片；课程资料只说明教过什么、预计检验什么，不虚构观众能力。 |
| 全矩阵、复杂镜头与通用素材编辑 | 根据作品需求扩展 | 先验证语义对象、稳定布局和音频时序；后续新增组件沿用这些基础。 |

这些投入遵循三个约束：一份牌局事实、一条正式编译和渲染路径、一组带修订与回执的编辑入口。避免让“预览看起来对”与“编码视频正确”变成两套实现。

## 教学形式与界面方向

2026-11-02 核对的一手资料支持四类可组合的节目形式。这里归纳的是官方公开的功能、课程形式与目录，不是好评排行，也不表示观看了完整付费课程。

| 节目形式 | 公开参考与设计启发 | 本项目的界面组合 |
| --- | --- | --- |
| 第一视角跟打与复盘 | [Upswing Play & Explain](https://upswingpoker.com/the-poker-lab-coaching/) 包含真实 session、手牌拆解与讲解；[更新目录](https://upswingpoker.com/upswing-lab-2-0-new-content-updates/) 可看到实时观察、逐手复盘等不同选题。 | 牌桌交代行动，关键决定切入分析，返回同一待决节点。连续 session 前史另列后续能力。 |
| 原理短课 | [PokerCoaching 课程介绍](https://members.pokercoaching.com/home1.php?lp=members_home1) 将聚焦一个主题的课程与手牌测验分别提供。 | 同一个案例贯穿问题、计算、限制与变化，公式按实际口播揭示。 |
| 范围研究 | [GTO Wizard Study Mode](https://help.gtowizard.com/study-mode/) 将上下文、全范围策略、具体手牌与不同指标分层呈现。 | 稳定画布保留牌局上下文；先展示范围分组，后续在可靠权重与单位齐备后展开矩阵和组合。 |
| 先答后讲 | PokerCoaching 的手牌测验先要求作答，再解释；开放题将方法用于新情况。 | 问题、真实留白、推理、答案与变化题使用同一表现编排；视频留白不冒充已记录学习者回答。 |

节目形式是内容组织方式，不各自建设新状态或新编辑器。导演台继续采用中央预览、右侧当前片段检查器、下方片段列表；播放控制保持固定。成片只输出牌桌或分析表面及字幕，导演资料不混入正常客户端。

## 实施次序

1. **冻结基线。** 保留历史报告与 106 项现有回归，新增检查独立记录。真实语音环境先探测并试生成，避免把受控测试引擎当成制作能力。
2. **决策资料。** 可选 `scene.analysis` 保存假设、条件、范围分组、基础计算与证据描述。公开动作前缀和决策事实参与审查指纹；修改后需重新确认。底池赔率只在适用局面计算，不冒充实际权益、行动频率或 GTO。
3. **共用表现。** 可选 `beat.presentation` 引用资料。横竖版共用语义对象；明确提示点绑定实际配音，各语言独立确认。返回牌桌不执行动作。清洁客户端与教学输出分别可查看。
4. **安全变化。** 从原有行动前缀改变指定动作，再用引擎重放；保留变化记录并要求内容复核。范围变化使用同一分析编辑流程，不复制牌局。
5. **导演与 skill。** 现有预览、片段列表和检查器加入表现设置、资料选择、提示点和问题定位。仍通过六方法的原子命令提交，Agent 不填写哈希、音频长度或两套像素坐标。
6. **课程制作。** 提供两个不同案例、三个递进章节、显式问题留白与条件变化。课程资料记录教学目标及先修假设，不声称观众已经学会。至少一个策略示范采用可独立验证的受限博弈均衡，并清楚标明其行动空间与范围限制。
7. **验收与交付。** 本地全回归、行为边界、随机帧一致性、横竖版实际编码、旧工程、便携导出、陌生案例冷启动。真实音轨与教学效果分别记录，未通过的项目不写成已验收。

## 必须阻止的错误

- 未来牌张、对手未公开底牌或预定动作泄漏到第一视角。
- 修改行动条件或范围后，旧的策略结论未经复核进入新版本。
- 回放/分析返回时重复执行动作，或使筹码产生变化。
- 新配音继续使用旧提示点；其他语言静默沿用中文提示时序。
- 一段旁白因画面拆分被重复混音；提问留白被字幕或结论提前填满。
- 将不完整、重叠的范围分组绘制为 100% 概率分布。
- 把引擎计算、作者提供的证据、独立模型验证与真实学习效果混为一谈。

上述检查覆盖结构化状态、资料与绑定。自由讲稿是否提前透露结果、是否误述范围、语气是否过度确定，仍需内容审查，不能把结构校验扩大为自动理解全部语义。

## 变更影响与复核边界

| 改动 | 自动处理或阻止 | 仍需内容判断 |
| --- | --- | --- |
| 下注、公共牌、初始筹码或公开行动前缀 | 引擎重放、计算重算、决定指纹失配 | 哪些范围、讲稿与结论需要重写。 |
| 范围或适用条件 | 分析资料待确认，已有事实轨迹保留 | 新假设是否有依据，结论是否仍成立。 |
| 本地策略依据文件 | 文件内容哈希校验，失配阻止正式渲染，包括缓存命中 | 文件内的模型、输入与推导是否足以支持主张。 |
| 配音、语言或声音设置 | 既有音频、字幕及提示点绑定按契约失效 | 新版重音、停顿、术语与图解的语义时机。 |
| 布局、颜色或聚焦 | 同一语义对象重新布局和渲染 | 视觉主次、密度与连续观看的舒适度。 |
| 课程顺序 | 与课程资料不一致时提供非阻断提醒 | 先修、重复、问题与答案出现顺序。 |

Agent 在明确复核后提交确认，系统负责确定性执行与完整性检查。首轮不建立词级依赖图，也不再内嵌自然语言规划器。

## 作品驱动的交付门槛

执行中用户明确调整了声音制作范围：只需生成部分真实声音验证，整套课程的高耗时配音由其他机器继续。因此本轮以已完成的横竖样片、陌生案例及现有有声均衡案例验证制作链；完整三集讲稿、课程编排与语言输入继续交付，未生成的声音保持明确待办。功能与本地回归验收不因此缩减。

1. **端到端样片：** 使用同一原生工程完成全桌、聚焦、分析、实际中文音频、精确提示点与返回决定；横竖版都检查实际 MP4。
2. **三集递进课程：** 分别讲价格与范围、受限模型与频率、条件变化与迁移。按实际语速安排时长，保留明确的问题留白。
3. **不同案例冷启动：** 无上下文 Agent 仅依赖 skill 制作不同牌面，完成变化与便携重开；与示例输入分开验收。
4. **语言与结构边界：** 英、日短片验证独立文字、声音与布局；旧工程、分支、多动作、复杂全下继续由原有回归覆盖。
5. **实际媒体：** 编码帧与编译边界对照；音轨与源音频独立关联，检查一段音频没有重复或截尾。语义审听与教学效果单列，不能由这些机械检查代替。

## 后续投入条件

完整范围矩阵、session 前史、更多动画/音效、章节缓存与全套多语言排演放在下一阶段，用实际制作耗时、重做原因、成片可读性和资源测量决定优先级。比赛/ICM、更多抽水模型和学习者记录由明确课程需求触发。没有收益证据时，不建设新的项目格式、并行接口或独立编辑状态。

下一轮建议依次投入：先根据连续试听调整逐段语速、重音和停顿；再按真实选题补范围矩阵、组合展开、箭头与镜头聚焦；需要讲剥削调整时增加可核对的 session 前史；制作耗时成为实际瓶颈时再做章节缓存。动画先用相同片段比较编码耗时、峰值内存与临时盘，再选择密度。每一步都应提升已有作品，并留下能够重复制作的输入。

| 阶段 | 可查看的下一项结果 | 复用基础与验收边界 |
| --- | --- | --- |
| P0 收尾 | 连续口播复听记录与明确修改时间点 | 复用音频修订、提示点失效与重绑定；ASR 只提供复听线索。 |
| P1：表达 | 箭头、短标记与局部镜头演示“这张牌影响哪组牌” | 复用现有牌张、座位和底池对象；语义聚焦不等于已经实现镜头缩放或自由画板。 |
| P1：研究 | 有权重与单位定义的组合数据、矩阵和组合展开 | 区分范围占比、行动频率与权益；模型条件与具体决定绑定后才显示精确策略主张。 |
| P1：对照 | 共同起点的两条路线及条件差异摘要 | 复用分支与重放；本轮安全变式仅覆盖指定动作替换，任意牌面自动变式另行验证。 |
| P1：连续实战 | 对手观察记录能追溯到前一手的可见动作 | 新增 session 前史时继续引用真实行动；第三集条件迁移不等于连续 session 已完成。 |
| P1：制作效率 | 有界动作动画、声音混音与局部重制的对照样片 | 用同片段实测耗时、内存和临时盘；只有实际重制成本需要时才引入章节缓存。 |
| P2：学习与赛制 | 可实际作答的练习、比赛/ICM、抽水模型 | 按明确选题增加，每种新数值口径有独立适用条件与回归。 |

这是减少重复状态和返工风险的工程取舍。当前没有受控的新旧制作成本与学习效果实验，不把“帕累托更优”写成已经得到实验证明的结果。

最终结果、运行命令、实际媒体与未通过项记录在 `TEACHING_ACCEPTANCE.md`。本文件描述计划，不代替验收报告。
