# 中文扑克讲解风格：公开作品研究与可执行模式

检索日期：2026-11-02。范围：中文原创创作者、自有课程与自有复盘文章；服务于 River Studio 的模式目录和 `poker-director`。这是风格研究，不是牌理认证或人气排名。

最有用的抽象单位是**讲解如何推进观众的判断**：交代当前难题、基于已知动作收窄范围、比较选择、行动后检查原来的判断。模式应约束这些可观察的行为，允许创作者自行选牌、选局型、安排幽默和悬念。不能用某位博主的姓名、口头禅或声音替代模式定义。

本轮覆盖 **5 个创作者、10 个具体公开作品/复盘文章**，另核对 2 个官方课程页面。10 个作品中，2 篇取得自有平台完整正文，其余取得原创页面的标题、简介或公共元数据；没有取得完整视频字幕，也没有完成连续试听。下文不会把课程目录当口播逐字稿，也不会把标题当真实视频开场。

## 从样本抽象出的 8 个模式候选

以下是**本研究提出的通用模式**，不是创作者原话，也不宣称每位创作者已经逐项实践。它们可以作为起点，允许改名、自定义、组合及场景级覆盖。选择时先看课程要使观众学会什么，再选叙事形式；不要求每片塞齐所有模式。

| 模式 | 适用局型与受众 | 可重复的讲解机制 | 最低可验收行为 | 可组合方向 |
| --- | --- | --- | --- | --- |
| 1. 贴身决策 | 6/9 人桌翻前，翻后收敛到单挑；入门到中级 | 固定自己座位；眼前问题→对手范围的一个关键变化→选择及下一街打算；结果回来后可修正 | 对手未亮牌时不用准确底牌作决策理由；至少一个关键决定讲出可检验理由；前后街计划相互对应 | 新手陪练、对手针对、一次关键决策短片 |
| 2. 一题讲透 | 某一位置、牌面或下注尺寸；各级别 | 先提出一个具体疑问，用一手主案例拆清，再用必要的小变体划边界 | 主问题能用一句话说清；变体真实改变了相关条件；结尾能说明何时不适用 | 求解对照、反常识纠错、多例归纳 |
| 3. 对手针对 | 现金局常见玩家类型，也可为明确锦标赛对手 | 观察过的行为→谨慎画像→基准策略→为什么偏离→读错时的代价 | “他很松”等标签有前序行为依据，或明确是预设；不把单次亮牌当永久画像；不把剥削频率说成无条件 GTO | 贴身决策、连续 session、分支对照 |
| 4. 范围与求解复盘 | 进阶单挑/多人池；必须使用对应模型 | 从直觉开始，把动作落实到范围/阻挡/尺寸；有证据时再解释求解结果与简化 | 声称的频率、EV或“最优”附匹配来源/设置；无证据时说清是思路或假设；不能把单挑解外推为多人解 | 一题讲透、反事实比较、主题多手 |
| 5. 先判断再揭晓 | 新手练习、短视频、反常识局面 | 在一个有意义的决定前留出思考空隙，随后讲理由，再揭示行动或结果 | 作答窗口前不泄露答案所需隐藏信息；选项都合法；解释为什么另外选择在此处较差或何时会变好 | 任意模式；可以不设选择按钮，只用口播与暂停 |
| 6. 一段比赛/牌桌经历 | 现金局 session、锦标赛主赛/决赛桌、多手主题 | 用人物和局势串联关键手；略过低信息过程；保留筹码、位置、形象的连续变化 | 每次跳手/跳时观众能理解；延续同一角色与上下文；输赢和决策质量分别评价；ICM/赏金因素有真实数据才作定量结论 | 贴身决策、自我纠错、赛事播报 |
| 7. 旁观拆招 | 全知复盘、官方赛事式播报，多人或单挑 | 先让行动流动，再挑关键节点解释双方压力；可单人讲，也可双人一问一答 | 讲解者、观众、玩家各自知道什么明示且一致；第一人称心理推断不能伪装成真实采访；双人对话有各自任务 | 轻量播报、深度停表复盘、互动预测 |
| 8. 误区修正/失败复盘 | 新手口诀、输赢归因、某类常见漏损 | 先呈现诱人的直觉或自己曾作的选择，随后用对照手/反例解释错误及边界 | 比较除目标变量外尽量一致；不能只用最终输赢证明选择错；幽默针对情境/自己，不靠侮辱观众或对手 | 一题讲透、反事实、主题多手、人物经历 |

模式 1–4、6、8 可直接由本轮正文/课程结构及原创简介支持其组织动机；模式 5、7 是进一步的产品设计推导，本轮中文素材没有取得足够逐字字幕来认证具体互动或双人对话流程。它们需要独立样片验收，不冒记为“已证实最受欢迎”。

对于本项目当前“六人桌从翻前开始、持续本人视角、翻后两人对抗”的重点，建议先用 **贴身决策 + 一题讲透**；需要讲 GTO 时叠加 **范围与求解复盘**；需要解释人群漏洞时叠加 **对手针对**。每手可以有不同表达，但不能在未声明的情况下切成提前知道对手底牌的叙述。

## 目录与 skill 只需保存的稳定维度

这些是设计建议，不要求另建一套执行引擎。应映射到已有场景、行动、旁白和音频能力；模式目录是一份默认参数与验收问题的来源。

1. **目标**：观众看完能作出哪一种判断；受众对术语、赔率、范围的基础。不要用必说术语数量代替难度。
2. **叙事结构**：单手逐街、单点深讲、多手经历、多例归纳、对照分支、问后揭晓。结构可组合，不固定段落句数。
3. **观察与知识**：固定玩家视角/第三方分析；哪些底牌已公开；未来街是否可见；事中推理和事后复盘在哪个节点转换。
4. **证据**：原始行动事实、对手读牌假设、经验建议、求解数据分别是什么；风格参考不能自动升级为打法证据。
5. **推理颗粒度**：播报、关键决策、逐街或范围深讲；多人弃牌可流动，关键下注前后可停下来。
6. **表达节奏**：语段跨行动、动作处留白、思考停顿、重点词重音；情绪用于疑问、犹豫、确认和反思，不能每句同强度。
7. **本地化**：目标语言、目标受众地区、字幕与读音分别检查；允许 all-in、3bet、cbet、坚果等实际通行混用，按受众解释。
8. **可扩展备注**：自定义开场、类比、笑点、教学目标和覆盖规则。验收看是否妨碍事实/视角/理解，不因偏离模板自动判错。

选择模式后保存本项目使用的完整配置快照和来源版本。目录将来改良时，旧项目仍能重现；同片可覆盖单个场景的深度或节奏，不需要复制成一批几乎相同的模式。

## 对导演台、客户端与流程的通用能力需求

本节依据模式需要提出验收要求，不声称当前实现已经具备或缺失，交由主任务对照源码核验。

| 需求 | 根因与通用解法 | 验收场景 |
| --- | --- | --- |
| 一段旁白跨多个合法动作 | 把语音绑定到动作时间线或可寻址节点；不要一句话生成一个重置桌面的“回合” | 多家弃牌时自然继续交代位置；语音不重开玩家计时，不改变当前行动人 |
| 同一手的原线与比较线 | 从同一合法快照派生后续行动；底池、后手、轮次由规则引擎计算 | 比较“转牌大注/过牌”时，公共前缀一致；不能为讲解方便手改出两个不同底池 |
| 跨手与选段 | 明确播放顺序、切换点及角色连续信息；每手仍是正常牌局模型 | 至少三手组成同一主题；切手后位置/盲注/筹码交代正确，无残留牌面 |
| 揭示与叙述知识一致 | 隐藏底牌和未来牌对画面、口播、字幕同时生效；复盘可在指定节点揭示 | 第一视角先判断再亮牌，再重放分析；切换前后的可知事实可审计 |
| 多人池为正常能力 | 不能把翻后强制收成单挑，也不能让多人场景复用单挑推理前提 | 六人翻前、三人看翻牌，其中一家全下形成边池；动作、信息和解说保持一致 |
| 风格证据和策略证据分开 | 同一资料可以只用于表达/结构；策略与数字另由规则、数据或匹配求解结果支撑 | 导入有行动词误写的复盘文章时，只提取叙事结构，不把文字错误写入行动线 |
| 听感验收独立存在 | 正确字幕或 ASR 不能证明语音自然；需按完整连续段试听，允许逐段返修而不重写整片 | 连续 60–90 秒有铺垫、动作和重点决定；读音、停顿、情绪不过度；没有碎句拼贴感 |
| 真实客户端保持稳定 | 模式选择不自动改变成教学 UI；分析卡、暂停题、范围图由具体作品选择是否使用 | 同一场景换两种讲解模式，牌桌仍保持真实在线客户端布局；横/竖版文字不挡牌与尺寸 |

## 模式一致性的验收

**事实与状态可以自动检查，风格效果需要作品审阅。** 自动检查至少覆盖合法行动、筹码/底池、重复牌、选定语言覆盖、音频缺失、可见信息设置、精确策略数字的来源。不能声称自动检查已经读懂了整段旁白的暗示或听感。

每个模式用两段不同牌面的样片验收：一段常规情形，一段具有冲突的情形。例如第一视角模式分别用六人桌转单挑、三人池有人全下；相同的是视角纪律、理由和节奏策略，不要求同一开场或同一句收尾。

人工/独立 Agent 审阅可以只答以下几个可观察问题：

- 开始二三十秒内，是否能知道这一段要解决的具体难题；有没有不相关铺垫？这是制作目标，不是声称存在统一最佳开场秒数。
- 关键行动前后，理由是否依赖当时可知的信息；有没有事后诸葛、为结果改写此前判断？
- 能否复述这一手最值得记住的一条判断及其适用条件，而不是只记住一串名词？
- 模式承诺是否兑现：逐街讲解是否确实接上后续计划，对比是否真的改变变量，对手针对是否有依据？
- 完整连续音频是否顺耳；轻重、停顿、情绪和桌上动作是否相互配合；玩笑是否自然且不抢走关键推理？
- 去掉创作者名字后，这种组织方式是否仍然成立；换一手牌、换一种语言是否仍可执行？

“去 AI 味”不宜做成禁词表或强制段子。更可靠的方向是具体处境、有限信息、真实选择、可承认的犹豫和可追踪的修正。专业程度来自推理和边界；记忆点来自一个清楚的难题和一个能迁移的判断。上述效果仍须用真实样片检验，不能用播放量倒推。

## 抓取与未完成证据

- B站网页由研究工具打开时部分返回 412；已知作品的公共 `x/web-interface/view` 能正常返回元数据，未登录账号，未规避登录/付费权限。4 个视频的公共 `x/player/v2` 返回空字幕列表，另外两作的 view 字段同样为空；这不证明画面没有烧录字幕，只表示本轮没有获得可读字幕。
- YouTube 正常页面请求返回需要登录确认的状态，字幕不可得；采用搜索工具对原创视频入口的可见元数据，不调用其他账号、代理或非公开接口。YouTube 计数标为索引快照。
- 没有下载、完整观看长视频；没有计算口播速度、笑点频率或受众地域；没有测量完播、留存、教学转化和胜率变化。
- 官网的营销承诺、收益数字与“最大/第一”等自述不视为独立事实或教学质量认证。本报告的模式候选根据可读结构与制作需求提出，不复制创作者脚本、声音或人设。

这些限制不妨碍先做可组合模式和底层能力，但应阻止系统把“研究建议”标成“复刻了某位大 V 的有效留存公式”。
