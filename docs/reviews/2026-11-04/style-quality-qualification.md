# 多风格讲稿与画面生产验收

2026-11-04；源码基线 `57b6a5584d643e97a23308dd2ecea79b167f6f45`，工作分支 `codex/style-quality-production`。本轮用户明确延期声音，验收对象是讲稿、风格机制、信息顺序、画面与制作流程；没有生成配音。

## 结果与范围

本机审片入口：`artifacts/style-quality-20261104/index.html`。13个节目、26个最终横竖版本：10种目录模式各一节目，另有两片新作者迁移复测和一片导演自行委派编辑的组合风格节目。每个节目提供完整稿、SRT、便携工程与回执。旧项目、失败稿、已替换成片与审阅记录均保留，不改写历史验收。

| 模式 | 本轮实际机制 | 文案/分镜与有界编码抽查 |
| --- | --- | --- |

| 决策竞猜 | 条件给齐、两次真实六秒留白、答案随后首次出现 | 通过 |
| 双人对谈 | 稳定中文角色、有增量的追问与反例、具体候选牌 | 通过；去除重复角色前缀后重新出片 |

这不是“第一稿必然优秀”的证明。首轮十种模式都需要修订；更新后的两片新作者首稿也有实质问题。可用的生产流程是创作、独立编辑、定向修订、实际成片验收，而不是模式标签和合法工程直接等于高质量。风格是否讨特定观众喜欢、是否提高完播率，尚未做真实受众实验。

## 效率实测

所有时间来自本轮回执或明确观察区间。下面最终26版使用的渲染回执包含章节缓存复用；不把它说成全部视频从零重做时间。

| 风格 | 横版渲染秒 | 竖版渲染秒 |
| --- | ---: | ---: |
| 跟打思考 | 68.70 | 66.01 |
| 手牌故事（最终修订） | 43.53 | 41.87 |
| 现场解说 | 89.28 | 85.16 |
| 基础陪练 | 17.87 | 17.36 |
| 决策竞猜 | 16.87 | 16.51 |
| 双人对谈（最终修订） | 13.43 | 13.30 |
| 范围实验 | 17.21 | 16.38 |
| 针对性剥削 | 15.32 | 14.70 |
| 路线对照 | 14.89 | 14.19 |
| 主题多例 | 19.61 | 19.02 |

最终13节目26版的渲染回执合计745.99秒，制作封装合计751.02秒；完整解码比对合计218.25秒；记录最高RSS约1.62GiB。正文/角色收尾重新生成四版，九张可见条件卡精简又重制八版，旧版均保留；故事稿每画幅复用一个未改章节。早期失败/已替换版本不混入最终回执合计，额外成本仍在原记录中。

新作者两片首稿从父dispatch前记录至交接约10分52秒，含阅读、构思、创作和交接；其脚本仅0.30秒，不能冒充总耗时。经过独立审稿与修订至新交接约35分48秒，此区间含父调度和等待，未连续分离纯工作量。另一自主导演从父dispatch前记录至最后交接约15分30秒，包含自行委派编辑和修订，父另补了一次原表达约束；不能宣称完全零外部提醒。

原公共plan合计1,522,530字节，等价分镜271,965字节，本样本减少82.14%。这是审读数据量减少，不是整体制作速度提升82%。当前主要瓶颈仍是创作与编辑判断；盲目重复渲染或增大语音算力不能解决它。

## 证据与完成边界

- 全部250项工程测试通过；包括原有真实Chromium/FFmpeg回归、新CLI、分镜投影、草稿时钟及实际音频到位后过期保护。build、doctor、skill结构校验与diff空白检查通过。
- 最终26版均有`VISUAL_PASS`，共1,044个实际关键/行动解码帧与源画面SSIM验证；源音频本轮有意缺省，没有声学通过结论。
- 独立编码审查按每节目横2/竖2抽查，共52张初始样本；两处定向收尾另查四张，可见条件文案收尾另查四张。完整26份SRT均有相应审查记录。没有声称连续看完全部影片、逐帧审美通过或物理手机验收。
- 新入口包含过滤、搜索、横竖切换、时点跳转、完整稿与工程。真实Chromium验证13个视频metadata、实际播放推进、切为1080×1920及390px窗口无横向溢出。
- 最终媒体、冻结工程、清单文件与哈希再校验在本机`qa/matrix-audit-final.json`（原`matrix-audit.json`保留）；入口交互在`qa/gallery-check.json`。独立审稿、失败、定向闭环在`qa/*editorial*`、`*encoded*`和`*copy-closure*`。
- 项目仍使用一个规则引擎、一个Compiler、一个预览/导出客户端。新增的是同一计划的只读审稿视图和完整的草稿语义，未引入第二种工程格式、TTS实现、执行核心或全局作业队列。

本轮通过的是文案和画面的生产闭环。真实配音到位后，需要复核动作/字幕/揭示绑定与自然听感；受众偏好和完播表现仍需实际发布后的数据。
