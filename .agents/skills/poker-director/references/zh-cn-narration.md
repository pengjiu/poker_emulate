# 面向内地玩家的德州口播

写给会在牌桌上讨论这手牌的人听。根据观众水平选术语与解释深度；地区习惯和用户给出的说法优先。下面是表达选择的例子，不是词汇白名单或固定脚本。

| 内容 | 常见表达与注意点 |
| --- | --- |
| AA / KK / QQ | 字幕可直接用牌面记号；口播按受众习惯说“AA”“口袋A”“一对K”等。读法以实际听感为准，不凭字符形式禁止某种地区叫法。花色影响推理时再读花色 |
| all-in / nuts / 3bet / cbet | 可自然说 all-in、推、坚果/坚果牌、nuts、三 bet、cbet；不必强制翻成中文长定义。首次是否解释取决于受众。3bet 是下注层级，不是固定三倍金额；坚果听牌不等于已经成坚果 |
| 下注尺度 | “打半池”“满池下注”“满池全下”“后手十个大盲”。区分剩余筹码、已投入和跟注金额；后文“十个”有明确单位上下文即可 |
| 范围与诈唬 | “他的价值牌有哪些”“哪些牌会拿来诈唬”“这手能不能抓”。价值与诈唬由相对范围决定，不能仅按表面牌型命名 |
| 百分比 | 说清是谁、在什么决策、以哪部分牌为分母：“下注里诈唬占三分之一”和“这手牌下注一半”是不同概念 |
| 牌局来源 | “一道河牌模型题”“这份牌谱”“六人桌打到河牌剩两人”各有含义。只在确有相应来源、人数和历史时使用 |

## 像讲牌，而不是朗读论文

从具体难题切入，讲清当前信息、备选动作、为什么选这个动作。用对手可能怎样应对来解释策略，让计算服务于选择。记忆点可以来自一个容易混淆的分母、一个反直觉的比较、一个有依据的判断；无需每片固定“三句话”或相同开场。

把“模型边界、来源、编排/随机抽样说明”放在需要理解的地方，一次说清。工程验收、文件格式、是否现场随机证明等制作信息保存在证据材料，不反复打断观众。示范某个混合策略分支时如实说明是示范，不假称实际随机抽样。

按完整意思和行动节点分段，不为每句话单独切一个音频/片段。自然的长短句、停顿和承接由推理决定。可以先给判断再解释，也可以保留悬念后揭示；选择适合内容的节奏，避免长时间只读抽象定义。字幕空间由系统分页处理。

专业感来自准确的范围、尺度和理由，不来自堆术语、反复念“均衡保护策略”，或虚构职业经历。保留目标玩家会自然使用的圈内词，不把 all-in、nuts、3bet、cbet 等排除为“黑话”；也不为了显得老练而刻意把每个词换成英文。避免生硬直译、喊口号和反复免责声明。

讲一手牌时，把重点落在当前难题和下一步计划：“我这枪想让什么牌跟”“这张转牌帮了谁”“被加注以后怎么办”。长短句随判断起伏，关键结论前后留一点空间。少用连续的“首先、其次、最后”和空泛的“核心在于”，也不把每句话都写成金句。让观众能跟着一个人的思路走完，而不是轮流听每个座位的内心独白。

## 配音前的冷读

把稿子当作要直接说给一位目标观众听的讲牌，重新读一遍：牌桌上会这样叫这手牌吗？每段有没有推进判断？术语在全片是否一致？收益是当前决策净收益还是整手牌输赢？动作前的理由有没有偷用后来亮出的底牌？

把连写的牌面和压缩的条件还原成能顺口讲出的完整意思；观众只听声音也应能复述关键牌面和你的顾虑。实时思考、已经做出的动作和回头复盘，各自的语气与画面时点要对应。具体怎么说由作者决定，验收看听懂了什么和动作是否抢先。

生成语音后核对牌面字母、金额、百分比、圈内英文词和语气停顿。字幕可保留 3bet/KK，使用 voice.set 的 pronunciations 给出实际读法；两者不能互相替代验收。换声音不能修复拗口的句子；先修稿，再重新生成受影响的音频。检查连续片段的听感与画面节奏，不能仅以字幕逐字一致或 ASR 无错判定表达自然。区分实际试听、自动信号检查和主观审阅，报告真正做过的检查。
